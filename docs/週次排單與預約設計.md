# 週次排單與預約設計

目前委託單僅保存 `queueMonth`（`YYYY-MM`）與手動 `queuePosition`，因此無法表示「8 月第一週」、預約週次或最後一般排單週次。後續將新增 `scheduleWeekStart`（該週的星期一 00:00）、`scheduleType`（`queued` 或 `reservation`）與 `estimatedWorkdays`。

系統只以 `scheduleType = queued` 的委託計算最後一般排單週次。新增一般委託時，預設週次為最後一般排單週次後兩週；沒有一般排單時，使用當週後兩週。預約委託不會計入最後一般排單週次，當系統計算的最後一般排單週次已到達或超過預約週次前一週時，預約委託將在讀寫時自動轉為一般排單。

週次顯示採用「M 月第 N 週」格式。月內順序不再由使用者輸入，改依同週的一般排單建立時間與加急優先規則生成。工作天工期以週一至週五計算，不納入例假日。

寫畫起約將移除 `type="month"` 與月內順序輸入。作畫項目內的備註改為跨欄寬文字區，讓組合頁可寫清楚位置與附加要求。指定交稿日會直接推導加急層級：當天為極限加急、隔日至 7 日為高度加急、8 至 30 日為中度加急、30 日以上但仍在最終排單日以內為一般加急。

總覽的工作量與最後排單週次只統計一般排單；預約單在獨立「預約畫約」群組呈現，不會擠入近期案件。近期案件需顯示加急層級、指定交稿日與預計工作天。現有總覽僅截取四張近期案件，而排畫連雲需保持所有群組完整顯示，並用週次鍵取代原本月份鍵。

案件卡片的期限列將改為在加急時明示「加急交稿：年月日」，並加上預約與工作天摘要。配色將從五色系改回既有墨綠米白權杖：深墨綠 `#283b31`、主要綠 `#355b48`、米白 `#fffdfa`，同時移除為五色系加入的全域硬編碼覆蓋橋接規則。

單元測試將覆蓋週次起點與標籤、最後一般排單週次、預約轉排單、工作天計算與交稿日對應加急層級。側邊欄收合狀態將以一致的寬度與置中容器包住頂部收合控制與底部品牌圖示，確保兩者位於同一垂直中心線。

視覺驗證顯示登入入口已從深藍灰五色系還原為深墨綠、米白與柔和綠色點綴；登入按鈕與說明文字的對比維持可辨識性。
