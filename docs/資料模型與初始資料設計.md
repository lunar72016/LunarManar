# 委託資料模型與初始資料設計

本系統以一張委託單代表一筆獨立工作。委託人可有多張委託單；第一版為個人使用，會以單一繪師帳號為資料擁有者，未來可透過分享權杖提供個別委託人唯讀進度。

## 委託單核心欄位

| 欄位群組 | 欄位 | 說明 |
| --- | --- | --- |
| 識別與排單 | `id`、`orderCode`、`queueMonth`、`queuePosition`、`createdAt`、`updatedAt` | 排單月份以 `YYYY-MM` 儲存，顯示時轉為中文月份；排序可以手動調整。 |
| 委託人 | `clientName`、`contactChannel`、`contactHandle` | 支援 Facebook、電子郵件、Threads、LINE、Discord、其他；帳號或聯絡資訊不在看板摘要中完整公開。 |
| 繪製內容 | `characterCount`、`artScopes`、`finishLevels`、`hasBackground`、`backgroundNote`、`requirements` | 繪製範圍與精緻度均可複選，以對應同時包含胸像與服設等複合委託。 |
| 加急 | `isRush`、`rushLevel`、`rushFee`、`rushMultiplier` | 優先採手動加急費以符合個別報價；倍率僅作記錄和估價輔助。 |
| 金額 | `basePriceMin`、`basePriceMax`、`basePriceText`、`depositAmount`、`depositText`、`finalPrice`、`finalPriceText`、`balanceAmount` | 數值欄位用於統計及自動計算，文字欄位保留 `400/1500↓`、`4-5000`、`?`、`+` 等原始記法。 |
| 付款 | `depositPaidAt`、`balancePaidAt`、`paymentMethod`、`paymentNote` | 訂金金額預設為底價或底價下限的 50%；尾款為最終定價減訂金。 |
| 草稿 | `sketchSentAt`、`sketchConfirmedAt`、`revisionNote` | 草稿確認前可留存修改說明；確認後可建立最終定價。 |
| 工作流程 | `status`、`statusHistory`、`completedAt` | 每次狀態變動儲存時間戳記與備註，供追蹤排單與付款歷程。 |
| 未來分享 | `shareTokenHash`、`shareExpiresAt`、`shareEnabled` | 第一版只保留結構；公開檢視頁只會讀取必要進度欄位。 |

## 進度狀態機

| 序號 | 狀態代碼 | 顯示名稱 | 正常前進條件 |
| --- | --- | --- | --- |
| 1 | `inquiry` | 詢問中 | 已收集需求並可估價。 |
| 2 | `confirmed` | 已確認 | 委託內容與底價完成確認。 |
| 3 | `awaiting_deposit` | 等待訂金 | 訂金通知已發出。 |
| 4 | `queued` | 排單中 | 訂金已標示收款，且設定排單月份。 |
| 5 | `sketching` | 草稿製作 | 輪到該委託或開始製作草稿。 |
| 6 | `sketch_confirmed` | 草稿確認 | 委託人確認草稿與修改內容。 |
| 7 | `awaiting_balance` | 等待尾款 | 最終價格已填寫，尾款通知已發出。 |
| 8 | `finalizing` | 完稿製作 | 尾款已標示收款，開始正式完稿。 |
| 9 | `completed` | 完稿 | 已完成返圖或交付。 |

系統允許繪師手動退回至前一階段或跳至適當階段，但會要求留下調整原因。付款狀態與流程狀態分離處理，以免因補登資料而造成不必要的流程限制。

## 初始範例資料轉換準則

| 原始格式 | 系統轉換方式 |
| --- | --- |
| `800/1600+` | `depositAmount=800`、`finalPrice=1600`、`finalPriceText=1600+`；加號保留在文字格式。 |
| `400/1500↓` | `depositAmount=400`、`finalPrice=1500`、`finalPriceText=1500↓`；向下符號保留在文字格式。 |
| `2000/4-5000` | `depositAmount=2000`、`finalPriceText=4-5000`；數值上限與下限可待確認後再補登。 |
| `1500/?` | `depositAmount=1500`、`finalPrice=null`、`finalPriceText=?`。 |
| `5200` | 原始紀錄未區分訂金與總價，存於 `basePriceText=5200`，付款欄位保留待繪師確認。 |

所有既有八月、九月委託資料會匯入為本機範例；其付款、草稿與進度狀態不由文字推測，而是保留為可在介面中快速補登的預設狀態。
