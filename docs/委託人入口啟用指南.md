# 委託人入口啟用指南

繪月錄現已提供公開委託填單與個人案件進度入口。委託人可選擇使用 Google 帳號登入，或不登入 Google、改以專屬高強度驗證碼查看自己的案件。設定稿與參考資料在第一版以雲端網址提交，不會直接上傳檔案。

## 一、Firebase Authentication 設定

請進入 Firebase Console 的 **Authentication → Sign-in method**，啟用下列兩種供應商。

| 供應商 | 用途 | 必要設定 |
|---|---|---|
| Google | 委託人使用 Google 帳號填單與查看自己案件 | 啟用 Google Provider 並儲存 |
| Anonymous | 未登入 Google 的委託人送出公開填單 | 啟用 Anonymous Provider 並儲存 |

此外，請在 **Authentication → Settings → Authorized domains** 確認 GitHub Pages 網域 `lunar72016.github.io` 已加入。Firebase 的 Google 登入流程需先在 Console 啟用 Google Provider；網頁登入可使用 Firebase SDK 的 Google Provider。[1]

## 二、發布 Firestore 規則

請至 Firebase Console 的 **Firestore Database → Rules**，將專案根目錄 `firestore.rules` 的內容完整貼上後發布。新規則會建立三種資料邊界：

| 資料 | 可存取者 | 備註 |
|---|---|---|
| `artists/{artistId}/...` | 僅繪師管理 UID | 原有完整畫約與設定資料 |
| `clientSubmissions` | 委託人僅能建立、查看自己的送件；繪師可完整管理 | 公開填單先進入「委託函」等待受理 |
| `clientProgress` | Google 委託人只看 UID 相符案件；驗證碼僅可單筆查看對應進度 | 僅保存公開進度白名單，不含價格、付款、內部備註與設定原文 |

> Firestore Rules 應以 Firebase Authentication 的 UID 限制資料存取，且查詢必須符合規則可能允許的文件範圍。[2]

## 三、委託人使用網址

GitHub Pages 發布後，請將下列網址提供給委託人：

```text
https://lunar72016.github.io/LunarManar/#/client
```

網址採用 `#/client` 形式，避免 GitHub Pages 的靜態網站在直接開啟子路徑時出現找不到頁面的情況。

## 四、繪師受理流程

委託人提交資料後，繪師登入工作台並依序操作：

1. 在側邊欄開啟 **委託函**。
2. 查看需求與雲端設定稿網址，選擇 **帶入寫畫起約並受理**。
3. 補齊報價、排單、付款與工期資料，再儲存畫約。
4. 系統會將案件公開進度快照連結至該委託人。Google 登入者使用帳號查看；驗證碼使用者則保留送件後顯示的專屬碼。

案件階段更新時，工作台會同步更新已公開的進度快照。公開畫面僅顯示案件代號、進度、排程週次、交稿期限與下一步說明。

## 五、建議測試順序

請先以無痕視窗測試公開入口，避免與繪師登入狀態混用。完成一筆測試後可從繪師端刪除。

1. 開啟公開網址，不登入 Google，填寫必要欄位並送出。
2. 保存畫面顯示的 `HY-` 驗證碼。
3. 繪師在 **委託函** 受理送件、完成寫畫起約。
4. 回到公開入口輸入驗證碼，確認只看見案件進度。
5. 以另一個 Google 帳號填寫與送出，再受理並確認 Google 登入後僅顯示該帳號案件。

第一版不支援檔案直接上傳。雲端網址應設定為可供繪師查看，並避免放入不希望透過連結分享的檔案。
